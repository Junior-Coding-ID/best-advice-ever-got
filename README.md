One sentence, up to 200 characters, on the best advice I ever received.
A judge model compares entries pairwise, and the line that carries the
most lived truth wins.

## Entry

> When I dropped a glass on my first shift at the diner, my boss told me to warn the cook coming through the door before I apologized.

132 characters, 1 sentence.

## How it works

`main.ts` is a Node-only program (plain JavaScript, no Deno APIs, no
dependencies). Running it writes the entry sentence to `entry.txt`,
then self-checks it: it reads `entry.txt` back byte by byte, verifies
the exact bytes, the character count (132), the 1–200 character gate,
and that the text is exactly one sentence.

```sh
node main.ts
```
